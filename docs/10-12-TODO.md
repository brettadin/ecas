# Transmission retrieval roadmap

Updated 2026-10-12. Transmission-spectrum retrieval is the active project track;
the emitted-flux workflow is deferred until this roadmap's validation milestones
are complete.

For implementation context, environment details, validation evidence, and
ordered handoff steps, see [10-12-HANDOFF.md](./10-12-HANDOFF.md).

## Completed foundation

- [x] Extract wavelength-dependent transit depths with uncertainties; display,
  bin, export, and explicitly hand off the measured spectrum.
- [x] Compare a clear, isothermal petitRADTRANS model in inferred top-hat
  wavelength channels; show residuals and diagnostic χ²/N without fitting.
- [x] Characterize time-correlated noise across integration-bin sizes without
  silently changing extracted uncertainties.
- [x] Add a conditional, one-gas VMR profile scan with a fitted constant depth
  offset. Its Δχ²=1 interval is exploratory, not a posterior or calibrated
  abundance result.
- [x] Audit the retrieval foundation and document the limitations below.

## Audit findings

- The atmospheric tests use injected pRT-compatible test doubles. They verify
  unit conversion, channel integration, offsets, scan behavior, and error
  handling, but do not verify a real petitRADTRANS installation or opacity data.
- The measured-channel comparison infers channel edges from wavelength centers
  and uses top-hat, uniform-wavelength integration. It does not apply a measured
  instrument throughput or line-spread function.
- The comparison's χ² assumes independent Gaussian channel uncertainties. It
  reports χ²/N as a diagnostic, not reduced χ² or a calibrated goodness-of-fit
  probability.
- Transit-depth extraction holds white-light geometry fixed and does not fully
  propagate out-of-transit baseline uncertainty or correlated noise into the
  depth uncertainties.
- The one-gas scan fixes all atmospheric inputs except one gas VMR and a constant
  depth offset. The nominal Δχ²=1 profile interval is conditional and does not
  account for parameter degeneracies or model inadequacy.
- No multi-parameter posterior retrieval or convergence diagnostics exist yet.

## Remaining work

### 1. Validate the real forward-model runtime — complete

- [x] Install a supported Fortran toolchain, petitRADTRANS 3.x, and the opacity
  data needed for a real test; do not treat test doubles as runtime validation.
- [x] Run a real forward spectrum and verify API compatibility, units,
  wavelength coverage, channel integration, and repeatability.
- [x] Record the pRT version, opacity sources, and setup needed to reproduce the
  validation. ECAS now registers discoverable MSYS2 Fortran runtime DLL paths
  before importing pRT on Windows.

### 2. Define a bounded retrieval and validation experiment

- [x] Specify the initial retrieval parameters, fixed inputs, priors, and
  explicit exclusions before implementing an optimizer or sampler. The first
  retrieval is conditional on one selected gas VMR plus a constant transit-depth
  offset. Temperature, gravity, reference radius/pressure, stellar radius,
  other gases, and the clear isothermal H₂/He model remain fixed. The VMR scan
  is bounded by an explicit positive grid; the offset is an unconstrained
  analytic nuisance fit. No posterior prior is implied by the Δχ² profile;
  any later Bayesian retrieval must state its own prior, including its measure.
  Clouds/hazes, instrument response, correlated noise, stellar contamination,
  temperature structure, and multi-gas inference are explicitly excluded.
- [x] Generate a seeded, binned synthetic transmission observation from the
  real forward model and test recovery with known channel noise and a depth
  offset. Boundary diagnostics now report when the best VMR or either
  Δχ²=1 crossing is outside the scan grid. Reusable validation helpers now
  support multiple injected VMRs and independent noise seeds; real-pRT
  multi-seed coverage results are still outstanding.
- [x] Decide the initial likelihood and treatment of nuisance offsets,
  instrument response, and correlated noise. The quick-look profile uses
  independent Gaussian measured-channel uncertainties, fits only a constant
  depth offset, and models neither instrument response nor correlated noise.
  Measured uncertainties remain distinct from any future modeled noise term.

### 3. Implement uncertainty-aware retrieval

- [ ] Implement a reproducible retrieval that returns uncertainty ranges,
  fit/likelihood diagnostics, and convergence or sampling warnings—not only a
  best-fit abundance.
- [ ] Validate recovery and uncertainty coverage on synthetic data before
  interpreting real observations. The new harness reports log-VMR bias,
  interval coverage, bounded-interval fraction, and boundary-limited fraction,
  but has not yet been run as a real-pRT multi-seed study.

### 4. Validate externally and integrate into ECAS

- [ ] Compare assumptions and behavior with suitable published transmission
  spectra and independent literature analyses; document data provenance.
- [ ] Integrate the validated workflow into the UI, project persistence, and
  exports. Show model assumptions, priors, uncertainty, diagnostics, and
  limitations with results.
- [ ] Add focused regression tests, run the full suite, and update this roadmap
  with verified outcomes and remaining blockers.

## Deferred

- [ ] Resume the separate emitted-flux analysis after the transmission

## Validation record

- Foundation audit: `tests/test_atmosphere.py` and `tests/test_timeseries.py`
  passed (23 tests) on 2026-10-12.
- Pylance diagnostics reported no issues in `app/core/atmosphere.py` or
  `app/ui/transit_panel.py` during the audit.
- Native Windows validation used petitRADTRANS 3.4.0, MSYS2 UCRT64 gfortran
  16.2.0, Microsoft MPI 10.1.12498.52, H₂O HITEMP R1000 opacity, and H₂-H₂ /
  H₂-He BoRi CIA opacity. A real 2.4–2.5 µm model produced 41 wavelength
  samples; channel-edge padding now allows its bin-center wavelengths to cover
  inferred observed-channel edges.
- A seeded 21-channel synthetic test injected H₂O VMR `1e-3`, a 40 ppm depth
  offset, and 2.5 ppm Gaussian noise. The real-pRT profile scan recovered VMR
  `1e-3`, offset 40.19 ppm, χ² 22.66 for 21 channels, and conditional Δχ²=1
  interval `[9.75e-4, 1.065e-3]`. This is a controlled recovery check, not
  evidence that the exploratory interval is calibrated for real data.
- Native Windows pRT import failed without the Fortran runtime DLL directory.
- ECAS now registers discovered MSYS2 paths before loading the optional backend;
  a real model call through the adapter succeeded without manual DLL setup and
  the helper has a focused regression test. Full UI-launch verification remains.
- Focused atmosphere/time-series tests passed (25 tests); the full suite passed
  (127 tests). Pylance reported no issues in the modified Python files.
